# Changelog

All notable changes to Pokefetch will be documented in this file. The project
uses semantic versioning once a version is tagged.

## Unreleased

### Added

- A Rust terminal greeting with Kitty graphics output and Ghostty icon support.
- Game-oriented, offline sprite bundles through FireRed and LeafGreen.
- Deterministic eight-color palettes and one-to-eight-line layouts.
- Dry-run-first asset import, bootstrap, doctor, and hosted validation tools.
- Manual packaging and draft-release preparation for versioned binaries.
